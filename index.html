LoopAlpha↗

I built a PyTorch research framework to test whether using gradients from each pass through a shared neural network block improves learning. Across two synthetic tasks and ten evaluation seeds, Muon achieved the lowest held-out error at every tested CPU time budget.

PythonPyTorchAutogradWalk-forward testing

02 / NOVEMBER 2026

BayesTrade↗

I built a Python library and synthetic market simulator to study whether Bayesian planning improves trade execution under uncertain liquidity. The POMDP lowered average costs versus TWAP in nominal switching. Against the same planner using only the current quote, the difference was close to zero.

PythonBayesian inferencePOMDP / BAMDPSimulation
Methods & findings +

I ran paired experiments across eight synthetic scenarios with queue-based fills, depth-limited orders, and market impact. The POMDP’s 95th-percentile cost under triggered liquidity stress was 23.99 bps versus 14.36 bps for TWAP. In a separate observed-regime test, learning fill rates saved 0.09 bps versus frozen priors (95% paired interval −0.17 to −0.01).
